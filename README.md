制作 mofu / Copyright 2026 mofu

企業の公表資料を探し、対象の登録・利用条件を確認する無料・広告なしの静的サイトです。個人の漏洩有無を判定するものではありません。ヘルプ・免責事項は dist/help.html と dist/about.html にあります。

## 自動更新
GitHub Actionsが毎時17分に登録した公式資料と公式サイトを確認します。定刻実行・網羅性は保証されません。GitHubの遅延・停止や取得制限があります。新着は「自動取得・未整理」、既存資料の変更は「再確認待ち」と区別します。対象条件を推測で生成しません。登録先以外の全企業を自動発見する仕組みではありません。

データの原本: data/reviewed-incidents.json。監視先: data/monitor-sources.json。内容を確認した後に要約と確認日を更新してください。既存URLの本文を再確認した場合だけ data/reviewed-source-hashes.json にそのURLと確認済みハッシュを記録します。

## 公開
GitHub Pages の Source を GitHub Actions に設定します。標準の公開リポジトリと無料サブドメインを使用し、有料API・広告・独自ドメインは使いません。提供元の料金・制限変更には従う必要があります。

公開対象は dist のみ。SECURITY.md の注意を確認してください。GitHubにソースを公開する場合は公開リポジトリ内のすべてのファイルとコミット履歴が閲覧されます。

公開前の確認:
```
python scripts/audit_public_files.py
python scripts/validate_site.py
```

## ニュース経由の新規事案発見
Security NEXT・ScanNetSecurity・INTERNET Watch・ITmediaの8本のRSSを取得し、記事本文の参照リンクから公式発表を確認します。data/news-sources.jsonで収集先と1回の件数上限を管理します。ニュース本文は保存・転載しません。確認不能な候補はdata/news-discovery-state.jsonのqueueに保留し、公開一覧には混ぜません。発表元の表示・日付・本文による照合は保守的な規則によるもので、全件の発見・正確な意味理解を保証しません。条件要約は人による確認が必要です。AI APIは使用しません。

直近3暦年の掲載条件は実行時の日本時間で更新します。RSSと月別記事から発見しますが、3年分すべての過去事案を収集したものではありません。



### Ver 1.3.0 の収集補強

RSSは8本（ITmedia総合・Mobile・NEWS全新着を追加）。Security NEXTの当月の記事一覧を確認し、過去分の補完中は未取得の月を毎回最大3か月ずつ確認します。過去の月は取得に成功したら定期巡回から外し、取得失敗と未処理の記事は再確認します。記事候補は処理前に保存し、RSSから消えた後も掲載対象の直近3年の範囲で追跡します。文字コードと本文選択を修正し、文字を抽出できるPDFでも発表元・発表日・見出しを確認します。対象条件・情報項目を自動推定する処理はありません。

追跡が必要な記事と理由は data/coverage-report.json、未着手件数は update-status.json とActionsの実行サマリーに記録します。候補数は未掲載事故数ではありません。直近3年分の全件を収集し終えたことや、今後の未掲載ゼロを保証するものではありません。
