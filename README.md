制作 mofu / Copyright 2026 mofu

企業の公表資料を探し、対象の登録・利用条件を確認する無料・広告なしの静的サイトです。個人の漏洩有無を判定するものではありません。ヘルプ・免責事項は dist/help.html と dist/about.html にあります。

## 自動更新
GitHub Actionsが毎時17分に登録した公式資料と公式サイトを確認します。定刻実行・網羅性は保証されません。GitHubの遅延・停止や取得制限があります。新着は「自動取得・未整理」、既存資料の変更は「再確認待ち」と区別します。対象条件を推測で生成しません。登録先以外の全企業を自動発見する仕組みではありません。

データの原本: data/reviewed-incidents.json。監視先: data/monitor-sources.json。内容を確認した後に要約と確認日を更新してください。既存URLの本文を再確認した場合だけ data/reviewed-source-hashes.json にそのURLと確認済みハッシュを記録します。

## 公開
GitHub Pages の Source を GitHub Actions に設定します。標準の公開リポジトリと無料サブドメインを使用し、有料API・広告・独自ドメインは使いません。提供元の料金・制限変更には従う必要があります。

公開対象は dist のみ。SECURITY.md の注意を確認してください。GitHubにソースを公開する場合は公開リポジトリ内のすべてのファイルとコミット履歴が閲覧されます。

公開前の確認:
```
python scripts/audit_public_files.py
python scripts/validate_site.py
```

## ニュース経由の新規事案発見
Security NEXT・ScanNetSecurity・INTERNET Watch・ITmediaの8本のRSSを取得し、記事本文の参照リンクから公式発表を確認します。data/news-sources.jsonで収集先と1回の件数上限を管理します。ニュース本文は保存・転載しません。確認不能な候補はdata/news-discovery-state.jsonのqueueに保留し、公開一覧には混ぜません。発表元の表示・日付・本文による照合は保守的な規則によるもので、全件の発見・正確な意味理解を保証しません。条件要約は人による確認が必要です。AI APIは使用しません。

直近3暦年の掲載条件は実行時の日本時間で更新します。RSSと月別記事から発見しますが、3年分すべての過去事案を収集したものではありません。

## Ver 1.3.12：無料AI補助の設定（運営者向け）

無料枠の利用可能回数・モデルはGoogle AI Studioで確認してください。無料枠の恒久性、実際の処理量や抽出精度を保証するものではありません。

1. https://aistudio.google.com/api-keys で、課金を有効にしていないプロジェクトのGemini APIキーを作成します。利用規約への同意とキーの作成はアカウント所有者本人が行ってください。
2. GitHubリポジトリの Settings → Secrets and variables → Actions → Secrets に、`GEMINI_API_KEY` の名前でキーを保存します。チャット、Issue、コード、公開ファイルには貼り付けないでください。
3. 同じ設定の Variables に `GEMINI_FREE_TIER_CONFIRMED` を追加し、未課金の無料枠プロジェクトであることを確認した場合だけ値を `true` にします。この設定は課金状態をGoogleに照会する機能ではありません。
4. Actionsの自動更新を実行し、`dist/update-status.json` の `aiSummary.status` を確認します。キー未設定なら `not_configured`、上限・認証エラーなら `paused` です。実際の成功は `acceptedSources` または `cachedSources` と各事例の根拠抜粋で確認します。

初期設定：gemini-3.5-flash-lite、1実行5回、直近24時間100回まで。無料枠の実際の上限はプロジェクトにより異なります。429では6時間待機し、認証エラーでは24時間待機します。有料モデル・他サービスへの自動切替はしません。同じ資料のハッシュが変わらなければAI結果を再利用します。根拠と一致しない回答、連絡先等を含む回答、流出件数と関係しない数字は採用しません。AIによる対象者の個別判定、漏洩確認済みへの自動変更はしません。

無料APIでは送信内容がGoogleの改善に使われ得ます。公開済みの公式資料のみを対象とし、問い合わせ先・担当者行・メールアドレス・電話番号等を除去した本文を送信します。利用者の検索語、保存内容、メールアドレス、流出データそのものは送信しません。

## 公式資料の取得失敗・画像PDFの確認

`data/source-recovery-report.md` が運営者向けの確認一覧です。未着手、取得不能、同じ事案か確認が必要な公式候補、要約に採用した公式PDFを区別します。候補数は事故数ではありません。原出典のアクセス制限を回避したり、見出しだけで別の事故を混ぜたりしません。取得制限には間隔を空けて対応します。

画像PDFはGitHub Actions上のPoppler/Tesseractで最大1資料・4ページを処理します。利用者のPCでは動作しません。結果は同じ確認一覧に残し、誤読のおそれがある数字をサイトへ自動採用しません。生PDFやOCR全文、APIキー、AIの未検証回答全文は保存・公開しません。手動確認した内容の採用は、既存の出典確認手順に従ってください。
